### I am building an AI product studio in public.

Not a resume. Not a code dump.  
This is a workshop for turning wishes into working AI products.

I am an AI Product Manager. My role is not to type every line. My role is to decide what should exist, why it matters, how the loop should feel, and where the AI must stop.

```text
wish -> product taste -> prompt system -> agent workflow -> prototype -> feedback -> sharper wish
```

## The Constellation

| Signal | Build | Field Note |
|---|---|---|
| Diagnose | [prompt-doctor](https://github.com/AgiWish/prompt-doctor) | A prompt quality scanner. It makes weak instructions visible, then turns them into stronger ones. |

## Product Taste

I like AI products that feel less like chat boxes and more like instruments.

- Clear input, visible reasoning, useful output.
- Agents with jobs, memory, boundaries, and feedback.
- Prompts treated as interfaces, not magic spells.
- Fast prototypes that test real product assumptions.
- Human taste at the center, model execution around it.
